# Optional production assets

The root of the repository contains everything Omarchy needs for the visual
theme. This directory contains non-executable extras and production records:

- `textless-masters/` — clean scene masters before final typography
- `ultrawide/` — four dedicated 3440×1440 alternatives
- `screensavers/` — optional high-contrast image-to-ASCII source images
- `social/` — 1200×675 contest/social card
- `source/` — emblem SVG, production manifest, prompts, and audit notes
- `concepts/` — documentation only; no conceptual mockup is presented as real

Nothing here runs automatically, and installing the theme does not alter a
screensaver preference or system behavior.
